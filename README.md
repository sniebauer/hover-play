# Hover! — playable browser build

Play at https://sniebauer.github.io/hover-play/.

This repository contains the compiled static game. Development source and native comparison tests are maintained separately in a private repository. The game runs JavaScript and WebGL, without DOSBox or Windows emulation.

Original Hover! art and audio © Microsoft Corporation, 1995. Unofficial preservation experiment; see [sources and fidelity notes](https://sniebauer.github.io/hover-play/sources.html).
