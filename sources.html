Recovered material

The HoverGame archive contains the original Windows game distribution: HOVER.EXE, four MAZ files, four TEX files, WAV effects, MUZ music, help, and an August 1995 README. That README identifies the Windows 95 CD location as Funstuff\Hover. All 84 game files have now been compared byte-for-byte with Funstuff\Hover on a local Windows 95B CD image and match the preserved package. No original C/C++ source code was present.

The format investigation uses Philip Searle's Merlin as a reference. Our Python reader independently decodes the MAZ/TEX structure and validates archive bounds, palette pixel spans, counts, and full file consumption. The original geometry and location coordinates are retained in JSON without normalization. Extraction manifest with source hashes.
